# 沣峪口老油坊 · 非遗油品溯源系统

> 中国国际大学生创新大赛 · 参赛项目方案

## 一、项目定位

「一物一码溯源存证 · 数字守护古法油品」——为沣峪口老油坊（劲金乡月）的非遗古法油品打造的可视化溯源系统。每一瓶油拥有专属「数字身份证」，生产全流程信息实时存档、加密上链、不可篡改，消费者扫码即可查看完整生产档案、辨别真伪。

## 二、技术架构

- **形态**：纯前端静态站（HTML / CSS / 原生 JavaScript），移动端优先
- **零依赖**：双击 `index.html` 即可演示，可部署至任意静态服务器
- **防篡改**：哈希链存证（Web Crypto API `SHA-256`），每个生产环节的哈希链式校验，篡改任一环节即导致整链断裂

```
溯源系统/
├── index.html          # 溯源主页面（扫码落地页）
├── css/style.css       # 暖色系中式主题样式
├── js/
│   ├── data.js         # 溯源数据（批次/环节/质检/匠人/存证）
│   ├── hashchain.js    # 哈希链存证算法（防篡改）
│   └── app.js          # 页面渲染与交互
├── assets/
│   ├── img/            # 生产环节影像（自视频抽取）
│   └── logo/           # 品牌标识
├── qr/                 # 产品专属二维码
└── README.md           # 本方案文档
```

## 三、核心功能

1. **产品档案** —— 产品/批次信息 + 唯一数字身份码 + 专属二维码
2. **全链路时间轴** —— 原料产地 → 生产全流程 → 质检报告 → 匠人工序详情
3. **生产环节记录** —— 每一步的影像 + 说明 + 时间戳 + 操作匠人
4. **质检报告** —— 检测项目 / 标准 / 结果
5. **匠人工序详情** —— 非遗传承人介绍
6. **哈希链存证** —— 链式校验 + 防篡改演示（信息不可篡改）

## 四、非遗古法榨油工艺流程（溯源链条）

```
① 原料晾晒筛选(菜籽·花生·芝麻) → ② 炒籽蒸坯 → ③ 研磨制坯 → ④ 包饼
→ ⑤ 木榨/石碾压榨取油 → ⑥ 过滤滤油 → ⑦ 油渣分离精滤 → ⑧ 灌装成品
```

## 五、防篡改机制

```
record_n.hash = SHA256( record_{n-1}.hash + record_n.data )
```

- 每个生产环节生成一条存证记录，其哈希值以上一环节哈希为输入
- 页面实时校验整条链，展示「链校验通过 / 校验失败」状态
- 演示：改动任意环节数据 → 该环节及后续所有哈希失效 → 页面报警，直观呈现「信息不可篡改」

## 六、创新点

1. **区块链思维落地**：以真哈希链实现可验证的防篡改，而非仅文案声明
2. **非遗 + 数字科技**：传统古法工艺与现代溯源技术融合，守护乡土非遗品牌
3. **AI 可视化**：全链路生产故事时间轴化呈现，消费端一键可查
4. **一物一码**：为每瓶油赋予专属数字身份，构建信任经济

4. 实现哈希链存证 hashchain.js
5. 实现页面渲染与交互 app.js
6. 生成产品专属二维码
7. 移动端适配与细节打磨
8. 编写方案说明与答辩材料（本文档）
